# Deposition Lens — portfolio copy

**GitHub description**
Offline deposition transcript review in Python/Streamlit: source-linked search, testimony highlights, date references, candidate conflicts, and reproducible citation tests.

**Portfolio description**
Built a Python and Streamlit application for examining numbered deposition transcripts. Implemented conservative TXT/PDF ingestion, BM25 keyword retrieval, original Q/A inspection, date-reference extraction, candidate conflict detection, citation navigation, and Markdown/JSON exports. Added regression tests and a manually annotated fictional evaluation sample. The UI uses no external AI service.

**Suggested resume bullet (after verifying the web app locally)**
- Built an offline legal-tech deposition review application using Python, Streamlit, transcript parsing, BM25 retrieval, citation-linked search, and reproducible tests; supported TXT/PDF imports and exportable evidence reports.

**Claims not to make**
- Do not call the app an autonomous agent, a semantic question-answering model, or an LLM-powered legal assistant.
- Do not call source-reference pass percentages legal factual accuracy.
- Do not claim it was deployed at a prior employer or saved attorneys time without independent evidence.
